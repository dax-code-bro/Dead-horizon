# Dead Horizon — Clothing System

---

## Overview
- Mix and match any combination of clothing items
- Create custom outfits or use premade ones from the wardrobe
- **Unlimited outfit slots** — save as many as you want, name them anything
- Preview items before buying
- Choose color for each item before purchase
- **100+ items per category minimum**
- Town-exclusive premade outfits

## Gameplay Effects

| Effect | How It Works |
|--------|-------------|
| **Warmth** | Heavy coats, cloaks needed in Mount Everest Range. Without them, cores drain fast. |
| **Heat** | Wearing heavy clothes in Sandy Dunes = overheat, stamina drains faster. |
| **Hunting** | Certain clothes reduce scent/visibility. Animals detect you slower. |
| **Stealth** | Dark clothes at night = harder to spot. Light clothes in snow = blend in. Affects enemy detection range. |
| **Noise** | Some boots/spurs make noise. Affects stealth and hunting. |

## HUD Indicators
- **Temperature indicator** — shows if you're too hot or cold for current outfit
- **Hunting warning** — small corner message: "Animals can get spooked by your clothing, visibility, or noise"
