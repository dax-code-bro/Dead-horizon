# Dead Horizon

A survival horror game built with Unreal Engine 5.4, released in episodic chapters.

## Structure

- **Chapter 1: The Awakening** — You wake up in an abandoned facility. Something is very wrong.
- More chapters coming soon...

## Project Setup

1. Clone this repository
2. Open `DeadHorizon.uproject` with Unreal Engine 5.4
3. Generate project files and build

## Controls

| Action     | Key              |
|------------|------------------|
| Move       | WASD             |
| Look       | Mouse            |
| Jump       | Space            |
| Sprint     | Left Shift       |
| Crouch     | C                |
| Interact   | E                |
| Fire       | Left Mouse       |
| Aim        | Right Mouse      |
| Reload     | R                |
| Flashlight | F                |
| Inventory  | Tab              |
| Pause      | Escape           |
